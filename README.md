# 平衡车控制

这是一个基于 STM32F103C8T6 的两轮平衡车学习项目，目前处于功能搭建和调试阶段。

## 实验进度

### 02-俯仰角与互补滤波实验

- 读取 MPU6050 三轴加速度和三轴陀螺仪数据
- 使用加速度计计算小车俯仰角
- 使用陀螺仪进行角度预测
- 通过互补滤波获得较稳定的俯仰角
- 通过 OLED 和串口输出姿态数据
- 使用 TIM1 进行定时采样和姿态计算

### 03-单角度环实现直立

- 建立以俯仰角为反馈量的单角度环 PID 控制
- 通过 PID 输出计算平均 PWM
- 通过差分 PWM 实现左右轮转向控制
- K1 控制小车启动和停止
- 小车倾角超过安全范围时自动停止电机
- 支持通过蓝牙实时调节 PID 参数和目标角度

## 当前内容

- OLED 数据显示
- 按键输入检测
- 双路直流电机 PWM 控制
- 双路编码器计数
- MPU6050 姿态传感器读取
- TIM1 定时中断

当前程序已完成姿态检测、互补滤波和单角度环 PID 控制，正在进行小车直立调试。后续将继续完善速度环、串级 PID 和小车行驶控制。

## 开发环境

- MCU：STM32F103C8T6
- 标准外设库：STM32F10x Standard Peripheral Library
- 编辑器：Visual Studio Code
- 工程插件：EIDE
- 编译器：ARM Compiler 5
