# 平衡车控制

这是一个基于 STM32F103C8T6 的两轮平衡车学习项目，目前处于功能搭建和调试阶段。

## 实验进度

### 02-俯仰角与互补滤波实验

- 读取 MPU6050 三轴加速度和三轴陀螺仪数据
- 使用加速度计计算小车俯仰角
- 使用陀螺仪进行角度预测
- 通过互补滤波获得较稳定的俯仰角
- 通过 OLED 和串口输出姿态数据
- 使用 TIM1 进行定时采样和姿态计算

## 当前内容

- OLED 数据显示
- 按键输入检测
- 双路直流电机 PWM 控制
- 双路编码器计数
- MPU6050 姿态传感器读取
- TIM1 定时中断

当前程序主要用于验证平衡车姿态检测和互补滤波算法。电机 PWM、编码器测速和蓝牙通信模块已经搭建，后续将继续完善速度计算、PID 控制和小车平衡控制。

## 开发环境

- MCU：STM32F103C8T6
- 标准外设库：STM32F10x Standard Peripheral Library
- 编辑器：Visual Studio Code
- 工程插件：EIDE
- 编译器：ARM Compiler 5
