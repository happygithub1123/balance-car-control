# 平衡车控制

这是一个基于 STM32F103C8T6 的两轮平衡车学习项目，目前处于功能搭建和调试阶段。

## 当前内容

- OLED 数据显示
- 按键输入检测
- 双路直流电机 PWM 控制
- 双路编码器计数
- MPU6050 姿态传感器读取
- TIM1 定时中断

当前程序主要用于验证各个硬件模块，编码器正在进行每圈计数和测速测试。后续将继续完善速度计算、姿态解算和小车平衡控制。

## 开发环境

- MCU：STM32F103C8T6
- 标准外设库：STM32F10x Standard Peripheral Library
- 编辑器：Visual Studio Code
- 工程插件：EIDE
- 编译器：ARM Compiler 5
